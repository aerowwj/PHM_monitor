2. RMS (均方根) 计算

实时统计加速度和陀螺仪的平方和，每次计算时清零重新统计：

rms_a = sqrt(acc_raw_sum_sq / cnt) * 0.00048828 # 转换为g单位
rms_g = sqrt(gyro_raw_sum_sq / cnt) * 0.061035 # 转换为°/s单位

噪声门限： RMS < 0.05g 时认为信号过小，直接返回0频

3. 峭度因子计算 (NumPy优化)

使用NumPy高效计算三轴加速度的最大峭度值：

# 去除直流分量 data_ac = data_buffer - mean # 计算各轴峭度 sq_diff = np.square(diff) m2 = np.mean(sq_diff, axis=0) # 二阶矩 m4 = np.mean(np.square(sq_diff), axis=0) # 四阶矩 kurt_arr = np.divide(m4, m2 ** 2, out=np.zeros_like(m4), where=m2 != 0) kurt = np.max(kurt_arr) # 取三轴最大值

4. 主频检测 (FFT分析)

基于汉宁窗FFT的复合频谱分析：

# 加窗 window = np.hanning(N) data_windowed = data_ac * window[:, np.newaxis] # 计算FFT (1024点) fft_res = np.fft.rfft(data_windowed, n=N_fft, axis=0) mag_sq = np.sum(np.abs(fft_res) ** 2, axis=1) # 三轴合成频谱 mag_composite = np.sqrt(mag_sq) # 在2-100Hz范围内寻找主峰 valid_mags = mag_composite[idx_min:idx_max] peak_idx = np.argmax(valid_mags) peak_val = valid_mags[peak_idx] noise_floor = np.median(valid_mags)

检测条件： peak_val > (noise_floor * 4.0) AND peak_val > 0.2

5. 健康评分算法 (动态扣分制)

基准100分，按偏离程度线性扣分：

  • 加速度RMS扣分： >10g开始扣分，每超过1g扣3分
  • 陀螺仪RMS扣分： >100°/s开始扣分，每超过1°/s扣0.2分
  • 峭度扣分： >3.5开始扣分，每超过0.1扣1分
  • 组内相对比较： 与同组平均RMS比较，超过20%开始扣分
  • 优秀条件： RMS < 2.0g 直接评为100分
# 扣分逻辑实现 deduction = 0.0 if r['rms_acc'] > 10.0: deduction += (r['rms_acc'] - 10.0) * 3.0 if r['rms_gyro'] > 100.0: deduction += (r['rms_gyro'] - 100.0) * 0.2 if r['kurt'] > 3.5: deduction += (r['kurt'] - 3.5) * 10.0 # 组内相对比较 if group_mean > 1.0: ratio_diff = (r['rms_acc'] - group_mean) / group_mean if ratio_diff > 0.2: deduction += (ratio_diff - 0.2) * 20.0 # 最终分数 r['score'] = int(max(0, min(100, 100 - deduction)))

6. 状态判定

  • 优秀 (绿色)： 分数 ≥ 90
  • 警告 (黄色)： 60 ≤ 分数 < 90
  • 危险 (红色)： 分数 < 60
  • 离线 (灰色)： 2秒未收到数据

7. 数据存储

机载存储： 200Hz原始数据存储到SD卡，二进制格式，最大1GB

网页存储： 1Hz特征数据存储到浏览器内存，CSV格式

二进制格式：时间戳(double) + 12个传感器 × 6轴 × short(2bytes) = 152 bytes/行
存储频率：严格5ms间隔 (200Hz)，零阶保持机制

8. 通信输出

  • MQTT (2Hz)： JSON格式特征数据，包含健康评分和状态
  • CAN FD (5Hz)： 0x391 ID，12字节健康分数 (0-100)
  • 控制命令： 通过MQTT TOPIC_CMD控制机载存储开关
