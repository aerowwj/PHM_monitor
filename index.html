📊 算法定义与数据源 (基于 smart_phm_node.py)

数据源: 12路 CAN总线 六轴IMU (加速度+陀螺仪) | 采样率: 200Hz

计算频率: 2Hz (每0.5秒计算一次) | FFT窗口: 800样本 (4秒数据)

1. 数据预处理

原始值 = 二进制解析(CAN数据包[2:8]) // 三轴16位有符号整数

2. 基础特征计算 (每 0.5 秒提取)

加速度 RMS = √(∑(acc²)/N) × 0.00048828 (g)
角速度 RMS = √(∑(gyro²)/N) × 0.061035 (°/s)
峭度 (Kurtosis) = E[(X-μ)⁴] / {E[(X-μ)²]}²

静止/降噪门限： 当 加速度RMS < 0.05g 时，判定为电机未启动或处于纯噪声状态，跳过高频计算，主频直接置 0。

3. 频域特征检测 (降频优化，每 2 秒计算 1 次)

基于 Hanning 窗的复合频谱分析。在 2~100Hz 范围内寻找峰值频率 fpeak。
有效主频条件： 峰值能量 > 4倍底噪均值 且 绝对幅值 > 0.2

4. 健康评分算法 (满分100，动态扣分制)

低振动豁免： 若 加速度 RMS < 2.0g，判定机器运行极其平稳，直接赋予 100分 (优秀)，不执行后续扣分计算。

  • ① 加速度超限扣分 (反映整体绝对震动)：
    当 Acc_RMS > 10.0g 时触发。超出部分每 1.0g 扣 2 分。
    D_acc = (RMS_acc - 10.0) × 2.0
  • ② 陀螺仪超限扣分 (反映机臂或机架的异常扭转)：
    当 Gyro_RMS > 100.0°/s 时触发。超出部分每 1.0°/s 扣 0.2 分。
    D_gyro = (RMS_gyro - 100.0) × 0.2
  • ③ 冲击异常扣分 (峭度识别，反映轴承磨损、缺珠或机械撞击)：
    非静止状态(RMS>0.5g)下，若 峭度 > 4.5 触发。超出部分每大 1.0 扣 1 分，此项最多扣 20 分。
    D_kurt = MIN( 20.0, (Kurtosis - 4.5) × 1.0 )
  • ④ 组内离群扣分 (反映同构件相对恶化)：
    将12个旋翼按机臂分为4组(每组3个)。计算同组正常电机的 RMS 中位数。
    若某电机震动高出本组中位数 30% 以上，触发离群扣分。
    差异比 R = (RMS_acc - 组内中位数) / 组内中位数
    D_rel = (R - 0.3) × 20.0
最终得分 = MAX( 0, 100 - D_acc - D_gyro - D_kurt - D_rel )

5. 状态分级 (基于最终得分)

  • 优秀： 分数 ≥ 90 (状态完美，可正常执行任务)
  • 良好： 75 ≤ 分数 < 90 (存在轻微振动，属于正常波动范围)
  • 警告： 60 ≤ 分数 < 75 (振动超标或存在异常冲击，建议落地检查桨叶/轴承)
  • 危险： 分数 < 60 (存在严重机械故障风险，建议立即降落维护)
